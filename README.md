# TWD i Norge

Et zombiespill i 3D som foregår i en norsk bygd, laget som én enkelt HTML-fil med Three.js.

## Slik spiller du

Åpne `index.html` i en nettleser. Alt ligger i den ene fila.

## Moduser

- **Historie:** kapitler gjennom bygda, helt fram til kapittel 100.
- **Sandkasse:** utforsk bygda fritt. Let i husene etter mat, drikke, våpen og bensin, hold sult og tørst i sjakk, kjør bil, og overlev dag og natt.
- **Flerspiller:** sandkasse sammen med venner.
  - Én spiller velger «Lag nytt spill» og får en kode på fire tegn.
  - De andre velger «Bli med med kode» og skriver den inn.
  - Husene er møblert. Se på en ting og trykk E for å ta den. Tab viser sekken.

Flerspiller bruker romtjenesten i Claude-artefakter, så den virker bare når spillet kjøres der. Utenfor kan du fortsatt spille alene.

| --- | --- |
| WASD | gå |
| Shift | løp |
| Klikk / F | slå |

| Tab | sekken |
